Golfscore

Wie gebruikt Golfscore, en met welke systemen buiten de app praat het? De binnenkant (app, API, database, website) komt pas in een C2-containerdiagram.

Doorgetrokken pijl: Golfscore of de persoon start het contact. Gestippelde pijl: GitHub start het contact (uitrol via SSH).

Relaties

  • Golfer → GolfscoreKiest de baan (met GPS-voorstel), het aantal holes en de spelers, spreekt of tikt de scores in en ziet stableford, differential en handicap. Werkt zonder internet en synchroniseert later.
  • Beheerder → GolfscoreBekijkt via de beheerpagina registraties, sessies, rondes, gedeelde spraak en GPS-punten, en geeft gebruikers het recht om GPS-punten vast te leggen.
  • Bezoeker → GolfscoreLeest op golf.kapital.nl de banen per provincie, de uitleg en de installatie-instructies. Zoekmachines en AI-assistenten lezen dezelfde pagina's, sitemap en llms.txt.
  • Golfscore → Telefoon en browserVraagt de locatie op voor afstand tot de green en baankeuze, en zet ingesproken tekst om via de spraakherkenning van de browser.
  • Golfscore → OpenStreetMapHaalt holes, tees en greens op via Overpass (via de server en GitHub Actions) en toont kaarttegels op de beheerpagina.
  • GitHub → GolfscoreHost de app op GitHub Pages, draait de tests en rolt de server uit via SSH met een sleutel die alleen deploy.sh mag starten.
  • Golfscore → Websites van clubsHaalt scorekaarten, course rating en slope op (met GitHub Actions); de waarden gaan na controle in de banenlijst.
