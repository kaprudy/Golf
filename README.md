# Scorekaarten (bronbestanden)

Originele scorekaarten, handicaptabellen en de HTML van de scorekaartpagina's van de banen in
`data/banen/` op de standaardbranch: eerst 80 banen rond Dedemsvaart, daarna alle banen in Nederland,
opgehaald op 28-10-2026.
Paden komen overeen met `scorecard.files` in `data/banen/<slug>/course.json`.
